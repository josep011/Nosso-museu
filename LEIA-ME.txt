NOSSO MUSEU — como atualizar no GitHub
1. No repositório, apague os arquivos antigos e envie TODOS os arquivos desta pasta (Add file > Upload files).
2. Commit. Em Settings > Pages, a branch main / root fica publicada.
3. Abra o link e aguarde 1-2 minutos.
As fotos dos quadros ficam só no aparelho de quem as adiciona (não vão para o GitHub).
